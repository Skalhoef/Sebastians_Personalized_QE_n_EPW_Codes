# Sebastians_Personalized_QE_n_EPW_Codes
This repository contains minimal modifications to Quantum ESPRESSO to support the GRIT code.

Changes include:

- modified the DOS-function from the QE package to work on finer grids (compatible for specific heat calculations close to zero temperature)
- modified and extended the prtgkk-function from the EPW package for further post-processing with the GRIT-code.
